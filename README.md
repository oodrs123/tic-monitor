# tic-monitor

# 🇮🇱 TIC / EPS / IM Japan News Monitor

บอทเฝ้าติดตามข่าว/ประกาศใหม่เกี่ยวกับโครงการแรงงานไทยไปทำงานต่างประเทศ
โดยอัตโนมัติ **ฟรี 100%** ผ่าน GitHub Actions ไม่ต้องมีเซิร์ฟเวอร์ของตัวเอง

เน้นเป็นพิเศษที่:
- ⭐ **โครงการ TIC** — ความร่วมมือไทย-อิสราเอล เพื่อการจัดหางาน (Thailand-Israel
  Cooperation on the Placement of Workers)

และติดตามเพิ่มเติมด้วย:
- 🇰🇷 โครงการ EPS (ไปทำงานเกาหลีใต้)
- 🇯🇵 โครงการ IM Japan (ฝึกงานเทคนิคที่ญี่ปุ่น)
- 🌏 โครงการแรงงานไทยไปต่างประเทศอื่น ๆ ทั้งภาครัฐและเอกชน

กรองเฉพาะข่าว/ประกาศที่ตีพิมพ์ **ตั้งแต่ปี 2026 (พ.ศ. 2569) เป็นต้นไป** และแจ้งเตือน
เฉพาะรายการที่ "ใหม่จริง" เท่านั้น (ไม่แจ้งซ้ำ) โดยเก็บประวัติไว้ใน `state.json`

---

## วิธีทำงาน (สรุป)

1. `monitor.py` ค้นหาข่าวผ่าน **Google News RSS** (ทนทาน ไม่ต้องพึ่งโครงสร้างเว็บใดเว็บหนึ่ง)
   ด้วยชุดคำค้นหาเฉพาะแต่ละโครงการ + ดึงหน้าประกาศข่าวหลักของกรมการจัดหางาน (doe.go.th)
   เป็นแหล่งเสริม
2. กรองข่าวที่ตีพิมพ์ก่อนปี 2026 ทิ้ง และเทียบกับ `state.json` เพื่อหาเฉพาะข่าวใหม่
3. ส่งข้อความแจ้งเตือนผ่าน **Telegram** (และ/หรือ Discord ถ้าตั้งค่าไว้)
4. บันทึก `state.json` กลับเข้า repo อัตโนมัติ (workflow commit ให้เอง)
5. **GitHub Actions** รันสคริปต์นี้ให้อัตโนมัติทุก 3 ชั่วโมง ตลอด 24 ชม. ฟรี
   (ปรับความถี่ได้ในไฟล์ workflow)

## ขั้นตอนติดตั้ง (ทำครั้งเดียว ใช้เวลา ~10 นาที)

### 1) สร้าง Telegram Bot (ฟรี) เพื่อรับการแจ้งเตือน

1. เปิด Telegram แล้วค้นหา **@BotFather**
2. พิมพ์ `/newbot` แล้วตั้งชื่อบอทตามต้องการ
3. BotFather จะให้ **Token** มา หน้าตาเช่น
   `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   → เก็บไว้ (นี่คือ `TELEGRAM_BOT_TOKEN`)
4. เริ่มแชทกับบอทของคุณ (กดปุ่ม Start หรือพิมพ์ `/start`) เพื่อให้บอทส่งข้อความหาคุณได้
5. หา **Chat ID** ของคุณ โดยเปิดลิงก์นี้ในเบราว์เซอร์ (แทน `<TOKEN>` ด้วย token จริง)
   หลังจากพิมพ์คุยกับบอทไปแล้วอย่างน้อย 1 ข้อความ:
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
   แล้วมองหาตัวเลขใน `"chat":{"id": xxxxxxxxx, ...}` → นี่คือ `TELEGRAM_CHAT_ID`

   ทางเลือก: ใช้บอท **@userinfobot** พิมพ์คุยด้วยจะบอก Chat ID ของคุณเองทันที

### 2) สร้าง Repository บน GitHub

1. สร้าง repo ใหม่ (Public หรือ Private ก็ได้ — Private ก็ใช้ Actions ฟรีได้ในโควตารายเดือน)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repo (ลาก-วางผ่านหน้าเว็บ GitHub ก็ได้
   หรือใช้คำสั่ง git ตามปกติ)

### 3) ตั้งค่า Secrets สำหรับแจ้งเตือน

ใน repo ของคุณ ไปที่ **Settings → Secrets and variables → Actions → New repository secret**
แล้วเพิ่ม:

| ชื่อ Secret            | ค่า                                   |
|-------------------------|----------------------------------------|
| `TELEGRAM_BOT_TOKEN`    | Token จากขั้นตอนที่ 1                  |
| `TELEGRAM_CHAT_ID`      | Chat ID จากขั้นตอนที่ 1                |
| `DISCORD_WEBHOOK_URL`   | (ไม่บังคับ) ถ้าอยากรับแจ้งเตือนใน Discord ด้วย |

> ใช้ Telegram อย่างเดียวก็เพียงพอแล้ว Discord เป็นตัวเลือกเสริม

### 4) เปิดใช้งาน GitHub Actions

1. ไปที่แท็บ **Actions** ของ repo แล้วกด "I understand my workflows, enable them"
   (ถ้ามีข้อความให้กดยืนยัน)
2. ทดสอบรันด้วยตัวเองก่อน 1 ครั้ง: ไปที่ Actions → เลือก workflow
   **"TIC / EPS / IM Japan News Monitor"** → กด **Run workflow**
3. ถ้าตั้งค่า Secrets ถูกต้อง คุณจะได้รับข้อความแจ้งเตือนใน Telegram ภายในไม่กี่วินาที
   (การรันครั้งแรกจะเก็บ "เส้นฐาน (baseline)" ของประกาศเก่าที่มีอยู่แล้วในหน้าเว็บ
   กรมการจัดหางาน โดยไม่ส่งแจ้งเตือนย้อนหลังทั้งหมด — ส่วนข่าวจาก Google News
   จะยังคงถูกกรองด้วยวันที่ตีพิมพ์ตามปกติ)

จากนั้นระบบจะรันอัตโนมัติ**ทุก 15 นาที** ตลอด 24 ชม. **โดยไม่มีค่าใช้จ่าย**
(GitHub Actions ให้โควตาฟรี **ไม่จำกัด** สำหรับ **repo public**; สำหรับ **repo private** ได้ฟรี
2,000 นาที/เดือน — งานนี้ใช้เวลาประมาณ 1-2 นาที/ครั้ง รันทุก 15 นาที = ~96 ครั้ง/วัน
≈ 100-190 นาที/วัน ≈ 3,000-5,700 นาที/เดือน ซึ่ง**เกินโควตาฟรีของ repo private**
→ ถ้าต้องการรันถี่ 15 นาทีจริง ๆ แนะนำให้ตั้ง repo เป็น **Public**
(โควตาฟรีไม่จำกัด) หรือถ้าอยากใช้ repo private ให้ลดความถี่ลง เช่น ทุก 30-60 นาที
ดูวิธีปรับในหัวข้อ "ปรับแต่งเพิ่มเติม" ด้านล่าง)

## ปรับแต่งเพิ่มเติม

### เปลี่ยนความถี่การตรวจสอบ

แก้ไฟล์ `.github/workflows/monitor.yml` บรรทัด:
```yaml
- cron: "*/15 * * * *"   # ทุก 15 นาที (ค่าปัจจุบัน)
```
ตัวอย่าง:
- ทุก 30 นาที: `"*/30 * * * *"`
- ทุก 1 ชั่วโมง: `"0 * * * *"`
- ทุก 3 ชั่วโมง: `"0 */3 * * *"`
- วันละครั้งตอนเช้า (08:00 น. เวลาไทย = 01:00 UTC): `"0 1 * * *"`

> ⚠️ GitHub Actions ไม่รับประกันว่า schedule จะรันตรงเวลาเป๊ะทุกครั้ง — ช่วงที่ระบบ
> คนใช้เยอะอาจดีเลย์ไปบ้าง (ปกติไม่กี่นาที) แต่โดยรวมยังคงรันสม่ำเสมอทุก ~15 นาทีได้ดี

### เพิ่ม/แก้คำค้นหา หรือโครงการที่ติดตาม

แก้ไฟล์ `monitor.py` ในส่วน `WATCH_GROUPS` เพิ่มคำค้นหาใหม่ในลิสต์ `queries`
ของกลุ่มที่ต้องการ หรือเพิ่มกลุ่มใหม่ทั้งหมด (คัดลอกโครงสร้าง dict เดิม)

### เปลี่ยนปีตั้งต้นของข่าวที่จะรับ

แก้บรรทัด:
```python
CUTOFF_DATE = dt.date(2026, 1, 1)
```

### รีเซ็ตประวัติ (เริ่มแจ้งเตือนใหม่ทั้งหมด)

ลบเนื้อหาใน `state.json` ให้กลับเป็น `{"seen": {}, "last_run": null}` แล้ว commit
(ระวัง: การรันครั้งถัดไปจะไม่ flood แจ้งเตือนย้อนหลังจากหน้า doe.go.th เพราะมีการเช็ค
`last_run is None` ไว้แล้ว แต่ข่าวจาก Google News ที่อยู่ในช่วงปี 2026+ จะถูกแจ้งใหม่ทั้งหมด)

## หมายเหตุสำคัญ

- ระบบนี้ **ดึงข้อมูลจากข่าวสาธารณะ** (Google News + หน้าประกาศสาธารณะของ doe.go.th)
  ไม่ใช่ช่องทางทางการของกรมการจัดหางาน จึงควร **ยืนยันข้อมูลกับเว็บไซต์ทางการ
  (toea.doe.go.th, doe.go.th)** หรือสายด่วนกระทรวงแรงงาน 1506 กด 2 ก่อนตัดสินใจสมัคร/สมัครงานเสมอ
  เพื่อป้องกันข่าวปลอมหรือมิจฉาชีพแอบอ้าง
- ถ้า Google News ปรับโครงสร้าง RSS หรือหน้าเว็บ doe.go.th เปลี่ยนแปลง อาจต้องปรับ
  `monitor.py` เล็กน้อย — ดู log ในแท็บ Actions ได้ทุกครั้งที่รัน
- ไม่ต้องกังวลเรื่องค่าใช้จ่าย: GitHub Actions (schedule + free tier),
  Telegram Bot API, Google News RSS ล้วนไม่มีค่าใช้จ่าย
